# Barrio al Día

Este es el repositorio inicial para la aplicación web **Barrio al Día**. 

## Stack
- **Frontend**: React 18 con Vite
- **Gestor de paquetes**: npm
- **Backend**: por definir (Node/Express, .NET, Python, Java, etc.)

## Scripts principales
| Acción | npm script |
|--------|------------|
| Desarrollo | `npm run dev` |
| Build | `npm run build` |
| Lint | `npm run lint` |
| Tests | `npm run test` |

## Primeros pasos
```bash
cd frontend
npm install          # instalar dependencias
npm run dev           # levantar servidor de desarrollo en http://localhost:3000
```
